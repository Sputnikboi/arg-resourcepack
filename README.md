# arg-resourcepack

Distribution host for the Minecraft ARG resource pack (MC 26.2).

`arg-resourcepack.zip` is served to players by the ARG server via
`resource-pack` in `server.properties`, pinned to a specific commit
so the SHA-1 stays stable.

Built from `~/minecraft-arg/resourcepack/` — do not edit this copy by hand;
run `./publish-pack.sh` in the ARG project instead.
